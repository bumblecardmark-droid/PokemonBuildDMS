1 Introduction and menu
ON SCREEN: Start a fresh run with run.bat or the IntelliJ run configuration. At the main menu, enter hello, then 99, then press Enter on a blank line.

READ ALOUD:
Hi, my name is Adriel Portillo Perez. This is Phase 1 of my Pokemon Build Management System. The program lets me load, display, add, remove, and update Pokemon build records. It also calculates a Team Readiness Score. Here, I am entering invalid menu choices. The program rejects them and keeps asking for a valid option.

2 Load the sample file
ON SCREEN: Choose 1. At the file prompt, press Enter on a blank line, enter missing.txt, then enter data.txt. Pause on the message 20 added, 0 skipped.

READ ALOUD:
The user enters the location of a text file. A blank location or a missing file produces an error without crashing the program. When I enter data.txt, the program loads twenty different sample records.

3 Display the records
ON SCREEN: Choose 2. Show the records and the final count. Scroll if necessary.

READ ALOUD:
This option displays all the stored records. Each build has nine fields: an ID, species name, primary and secondary types, role, base stat total, usage rate, team selection status, and updated date.

ON SCREEN: Choose 5 and enter 102. Show the nine-field update menu. Choose 7 for usage rate. Enter 150, then 30. Choose 2 and point to Rotom-Heat with usage 30.00.

READ ALOUD:
The update menu lets me change any field, including the ID and date. Here I am changing Rotom-Heat's usage rate. A percentage above one hundred is rejected. The valid value of thirty is saved and appears in the updated data.

7 Calculate the custom score
ON SCREEN: Choose 6. Show the selected builds, calculation breakdown, and score of 64.79 out of 100. This result assumes the usage-rate edit in step 6.

My custom feature is the Team Readiness Score. It uses only the selected builds and combines their average base stats, represented types, different roles, and average usage. The program shows the points from each part of the formula. With the change I just made, the score is sixty-four point seven nine out of one hundred.

READ ALOUD:
The program is divided into classes for the build object, validation, storage, file loading, calculation, and console actions. The comments identify each class and explain method purposes, arguments, and return values.

ON SCREEN: Return to the running console and choose 0. Show Goodbye.
