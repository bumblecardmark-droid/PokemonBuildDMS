Pokemon Build Management System - Module 7
Adriel Portillo Perez

1. Extract the entire ZIP.
2. Open the PokemonBuildDMS folder.
3. On Windows, double-click run.bat.
4. At the menu, type 1 and press Enter.
5. At the file prompt, type data.txt and press Enter.
6. Type 2 to display the 20 records.
7. Type 6 to calculate the sample team score: 64.45/100.
8. Type 0 to exit.

Requires Java 8 or newer. If Java is not recognized, install/select a Java JDK
and confirm that the java command is on PATH. IntelliJ can also run Main.java.

Source files: src/dms/*.java
Executable: dist/PokemonBuildDMS.jar
Samples: data.txt
Detailed setup: README.md
Recording script and exact inputs: DEMO_GUIDE.md
